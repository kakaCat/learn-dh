# Cordis 插件系统

## 核心概念

### 什么是插件？

在 Cordis 中，**插件就是实现了 Service 的对象**。插件有两种形式：

#### 1. 函数形式

```typescript
function myPlugin(ctx: Context, config: Config) {
  // 插件逻辑
}

// 可选：声明依赖
myPlugin.inject = ['database', 'logger']

// 可选：apply 方法
myPlugin.apply = (ctx: Context, config: Config) => {
  // 插件逻辑
}
```

#### 2. 类形式

```typescript
class MyService extends Service {
  constructor(ctx: Context, config: Config) {
    super(ctx, 'myService') // 注册服务名
    // 初始化逻辑
  }
  
  // 服务方法
  doSomething() {
    // ...
  }
}

// 声明依赖
MyService.inject = ['database']
```

## 插件的生命周期

### 1. 注册阶段
```typescript
ctx.plugin(myPlugin, config)
```

### 2. 依赖解析
- Cordis 检查 `inject` 声明的依赖
- 等待所有依赖的服务就绪

### 3. 激活阶段
- 调用 `apply(ctx, config)` 或构造函数
- 注册服务到 `ctx.<key>`

### 4. 卸载阶段
- 自动调用所有注册的 disposer
- 清理事件监听器
- 移除服务注册

## 服务注册

插件通过 `ctx` 暴露服务：

```typescript
class ToolsService extends Service {
  constructor(ctx: Context) {
    super(ctx, 'tools') // 注册为 ctx.tools
  }
  
  register(name: string, tool: Tool) {
    // 注册工具
  }
}

// 其他插件可以使用
ctx.tools.register('myTool', {...})
```

## 可逆效果（Reversible Effects）

所有注册都应该是可撤销的：

```typescript
function myPlugin(ctx: Context) {
  // 方式1：使用 ctx.effect()
  ctx.effect(() => {
    // setup
    const timer = setInterval(() => {}, 1000)
    
    // 返回 disposer
    return () => {
      clearInterval(timer)
    }
  })
  
  // 方式2：使用 Cordis 辅助方法（自动处理 disposer）
  ctx.on('message', (data) => {
    // 事件处理
  })
}
```

## 实际例子

### 简单的日志插件

```typescript
class Logger extends Service {
  constructor(ctx: Context) {
    super(ctx, 'logger')
  }
  
  log(message: string) {
    console.log(`[LOG] ${message}`)
  }
  
  error(message: string) {
    console.error(`[ERROR] ${message}`)
  }
}

// 使用
const ctx = new Context()
ctx.plugin(Logger)
ctx.logger.log('Hello World')
```

### 带依赖的插件

```typescript
class DatabasePlugin extends Service {
  constructor(ctx: Context) {
    super(ctx, 'database')
  }
  
  async query(sql: string) {
    ctx.logger.log(`Executing: ${sql}`)
    // 数据库操作
  }
}

// 声明依赖 logger
DatabasePlugin.inject = ['logger']

// 使用
ctx.plugin(Logger)
ctx.plugin(DatabasePlugin) // 会等待 logger 就绪
```

## 关键要点

1. ✅ **插件是服务的提供者** - 通过 `ctx.<key>` 暴露
2. ✅ **依赖通过 inject 声明** - 不需要手动排序
3. ✅ **所有注册都可逆** - 通过 disposer 清理
4. ✅ **插件可以热重载** - 卸载时自动清理
