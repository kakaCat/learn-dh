# Context 压缩模块（未实现）

## 为什么需要压缩？

LLM 有上下文窗口限制：
- GPT-4: 8K-128K tokens
- Claude: 200K tokens

随着对话进行，消息历史会越来越长，最终超过限制。

## 压缩策略

### 1. Token 计数

首先需要统计当前使用的 tokens：

```typescript
interface TokenCounter {
  // 计算文本的 token 数
  count(text: string): number
  
  // 计算消息列表的总 tokens
  countMessages(messages: Message[]): number
}
```

### 2. 滑动窗口

保留最近的 N 条消息：

```typescript
function slidingWindow(messages: Message[], maxTokens: number): Message[] {
  let total = 0
  const result: Message[] = []
  
  // 从后往前
  for (let i = messages.length - 1; i >= 0; i--) {
    const msg = messages[i]
    const tokens = countTokens(msg)
    
    if (total + tokens > maxTokens) break
    
    result.unshift(msg)
    total += tokens
  }
  
  return result
}
```

### 3. 摘要压缩

将旧消息摘要成一条：

```typescript
async function summarize(messages: Message[]): Promise<string> {
  const response = await llm.chat({
    messages: [
      {
        role: 'system',
        content: 'Summarize the following conversation in 2-3 sentences.'
      },
      ...messages
    ]
  })
  
  return response.content
}
```

### 4. 重要性采样

保留重要的消息：

```typescript
function importanceSampling(messages: Message[]): Message[] {
  // 计算每条消息的重要性分数
  const scored = messages.map(msg => ({
    message: msg,
    score: calculateImportance(msg)
  }))
  
  // 排序并保留前 N 条
  scored.sort((a, b) => b.score - a.score)
  
  return scored.slice(0, 10).map(s => s.message)
}

function calculateImportance(msg: Message): number {
  let score = 0
  
  // 用户消息更重要
  if (msg.role === 'user') score += 10
  
  // 工具调用很重要
  if (msg.tool_calls) score += 20
  
  // 长度也是一个因素
  score += msg.content?.length || 0
  
  return score
}
```

## Compaction Service

```typescript
interface CompactionStrategy {
  // 压缩消息列表
  compact(messages: Message[], maxTokens: number): Promise<Message[]>
}

class CompactionService extends Service {
  private strategy: CompactionStrategy
  
  constructor(ctx: Context, strategy: CompactionStrategy) {
    super(ctx, 'compaction')
    this.strategy = strategy
  }
  
  async compact(messages: Message[], maxTokens: number): Promise<Message[]> {
    return this.strategy.compact(messages, maxTokens)
  }
}
```

## 在 Agent Loop 中使用

```typescript
async runStep(agent: Agent): Promise<boolean> {

  let messages = this.deriveMessages(events)

  const tokens = countTokens(messages)
  const maxTokens = 100000 // 100K
  
  // 如果超过限制，压缩
  if (tokens > maxTokens) {
```

## 关键要点

1. ✅ **Token 计数** - 知道何时需要压缩
2. ✅ **多种策略** - 滑动窗口/摘要/采样
3. ✅ **保留重要信息** - 不丢失关键上下文
4. ✅ **增量压缩** - 不是每次都重新压缩

## 实现提示

- 使用 `tiktoken` 库计算 OpenAI tokens
- 保留系统消息和最近的几条消息
- 工具调用和结果成对保留
- 记录压缩事件到 session 日志
